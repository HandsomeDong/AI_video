# 剧情参考图、多人空间与连续性实战规范

本参考用于先生成剧情参考图再制作视频、多人卡通角色同框、第一视角或一镜到底、以及包含明确遮挡、内外分区和手持道具的场景。目标是优先解决最容易返工的四类问题：**角色串模、比例悬殊、空间错误、连续性漂移**。

## 1. 参考素材必须单一职责

先在内部建立素材表，固定每张图只承担一个主职责：

- 人物三视图：只锁定该人物的五官、轮廓、材质、身体比例与识别点；不使用白底或原背景。
- 场景图：只锁定建筑布局、固定家具、材质、光线与空间纵深；场景图里若有错误人物，不继承其身份、比例或姿势。
- 姿势图：只迁移身体姿态、重心和表情强度；不改变人物模型。
- 前后关键帧：只定义动作链的起点、转折点与终点，不代表必须切镜。

使用多个角色参考时，必须逐一命名绑定，禁止用“左边那个”“黄色角色”等临时称呼。当前用户提供的专门人物图优先级最高。

## 2. 参考图数量以动作锚点为准

- 连续单场景通常先做2—3张：起始状态、核心转折、结束状态。
- 参考图负责锁定身份、空间和关键姿态；时间变化、细微动作与运镜交给视频 Prompt。
- 不为每句台词都生成一张图。图越多不一定越稳定，职责重叠反而会制造冲突。
- 用户明确说“一张即可”“两三张即可”时严格控制数量。

## 3. 先校准人物模型，再安排站坐

多人同框前，先把角色抽象为同一空间中的“标准站立模型”：

1. 确定每个角色的基础站立高度、躯干最宽处和头身比例。
2. 同龄同学若无特殊设定，基础站立高度差通常控制在约5%以内，躯干量级保持接近。
3. 再把人物放进坐、蹲、弯腰或远近位置；**坐下只改变骨架姿势，不能整体放大模型**。
4. 用共同地面、桌面高度、椅背和玻璃门框复核尺度；不要只凭画面占比判断。
5. 透视只解释合理的远近变化，不能让近处人物变成小人、远处人物反而像巨人。

若角色有特殊头身比，必须写成识别锁：例如奶蛙的小头、袋鼠的长耳柱、牛来的宽厚橙色绒毛身体。不要用统一的“大头萌系”模板覆盖三视图。

## 4. 先画空间链，再画构图

复杂场景先用一句话还原平面：

**摄影机位置 → 前景人物 → 障碍物/边界 → 后景人物 → 目标物 → 可行出口。**

至少检查：

- 谁在室内、谁在室外，玻璃、门或柜台是否真的位于两者之间。
- 桌子、椅子、蛋糕、书包等是否全部处在正确区域，是否穿过墙、玻璃或人物。
- 人物的视线是否能看见目标；躲藏者是否确实被树干、墙角或柜体挡住。
- 离开方向是否与场景出口一致；不要让人物朝商店内部方向“离开”。
- 前后景距离是否足以表现遮挡和透视，而不是把所有人压在同一平面。

### 玻璃内外场景

- 明确摄影机在哪一侧、玻璃平面的位置、人物距玻璃与桌子的距离。
- 玻璃反射只服务材质与天气，不能复制、合并或遮住角色。
- 店外人物与店内人物之间必须有可读的玻璃边界和空间纵深。

### 树后观察场景

- 观察者与同伴应同时位于遮挡物后侧；目标人物的视线不能直接扫到他们。
- 第一视角在目标与同伴之间转动时，先确定左右关系，再写镜头摆动，避免人物跨越树干或换边。

## 5. 道具连续性只写确定事实

- 记录道具“在谁手里、是否损坏、最后放在哪里”。
- 已经建立右手或左手后，后续不得无过程换手。
- 若左右手不承担剧情作用且容易描述错，使用“拿着、捡起、递出”等中性措辞，不强行指定左右。
- 用户要求去掉某个道具时，后续参考图与 Prompt 都必须删除，不得因旧图重新生成出来。
- 包装、铅笔、手机、礼物等不能重复出现、凭空消失或穿过手掌。

## 6. 第一视角不是僵硬固定机位

- 摄影机就是角色眼睛，机位高度与角色体型一致；只在剧情需要时露出手或身体边缘。
- 即使不说话，也保留极轻的呼吸起伏、重心调整与观察性转头，避免监控画面般完全静止。
- POV角色说话时，镜头可随下颌、呼吸和身体重心产生小幅自然晃动。
- POV角色大笑时，用有节奏的小幅上下与左右抖动表现身体震动；不能变成失控手持或模糊画面。
- 若用户明确要求固定镜头，则让人物走入固定构图完成动作，不用摄影机追着人物找位置。

## 7. 一镜到底与电影式对话要区分

只有用户明确要求一镜到底时，才锁定为连续镜头，并写清：

**起始机位和景别 → 连续移动路径 → 中途主体交接与焦点变化 → 结束位置和最后构图。**

- 明确“绝不切镜、无转场、无隐形跳切”。
- 多张参考图是连续路径中的空间锚点，不是切镜列表。
- 环绕、穿玻璃、由第一视角转第三视角等复杂运动，要说明摄影机如何保持同一空间轴线。
- 用户未要求一镜到底的常规双人对话，优先使用电影式正反打、过肩和反应镜头；不要为了形式强行一镜到底。

## 8. 情绪转折必须绑定可见触发点

- “眼眶蓄泪”与“眼泪落下”是两个状态。若用户指定触发点，例如挂断电话后才哭，之前只能让泪水停在下眼睑。
- 悲伤场景中的天气强度按用户要求执行；用户明确“大雨”时，画面需出现密集雨线、积水涟漪、玻璃水痕与雨声，不能退化成零星小雨。
- 崩溃大笑、低头丧气等姿势若有专门动作图，动作图只负责姿态和表情，人物身份仍由三视图负责。

## 9. 电话与手机画面

- 用户说“不需要展示手机里的内容”时，屏幕始终背向镜头、熄灭或画外，不生成通话UI、头像、文字或父母画面。
- 一镜到底电话戏可用手机外放声音承载画外角色，摄影机持续观察接听者的反应。
- 对白较长时先估算朗读、理解、动作和尾镜余韵；只有用户明确授权稍快语速时才压缩语速。

## 10. 参考图与封面交付前自检

生成后必须视觉检查，不要只因为工具成功就交付：

- 每名角色是否仍像各自三视图，是否发生五官、材质、耳朵、尾巴、角或头身比串模。
- 同龄角色的基础体型是否接近，坐姿与透视是否被误当成模型缩放。
- 内外、前后、左右、遮挡、出口和视线是否符合剧情。
- 桌形、椅子、蛋糕、小蛋糕、书包等关键物是否在正确人物面前和正确区域。
- 参考图是否完整显示需要视频继续的动作空间，人物是否被无意裁切。
- 横版与竖版封面是否独立构图，而非机械裁切；角色身份与空间关系是否在缩略图下仍可读。

发现问题时，一次只修一个主问题，并在修改 Prompt 中重复其他已确认不变量。若角色身份、尺度和空间同时错误，应从三视图与空间平面重新生成，而不是继续在错误图上局部修补。

## 11. 版权误判的提示词卫生

- 使用用户提供的原创角色参考时，用外形、材质和比例描述角色，不主动添加影视作品、动画品牌、工作室或艺术家名称。
- 不生成无剧情作用的品牌Logo、店招、手机UI、头像或现成作品元素。
- 版权提示出现时，保留用户的原创剧情和人物参考，删除可能触发联想的品牌式措辞，改用中性、可见、原创的视觉描述；不要擅自改变剧情结局。
