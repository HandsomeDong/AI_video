# Seedance 2.0 全能参考导演系统

## 1. 先给素材分工，再写剧情动作

存在2个及以上素材时，先建立职责映射。

### 人物锚点

适合使用：清晰人物图、三视图、服装图。

锁定：
- 面部
- 发型
- 身材
- 服装
- 身份

### 场景锚点

适合使用：纯场景图、建筑图、机库/房间/街道参考。

锁定：
- 空间结构
- 建筑布局
- 主体位置
- 光线
- 地面
- 色调

### 动作模板

适合使用：动作参考视频、姿势图。

只迁移：
- 动作轨迹
- 身体节奏
- 重心变化
- 手脚关系

不迁移：
- 参考演员身份
- 参考服装
- 原背景

### 摄影模板

参考视频可只承担：
- 镜头起点
- 运镜路径
- 镜头速度
- 景别变化
- 转场结构

### 情绪模板

参考视频可只承担：
- 表情变化过程
- 呼吸节奏
- 停顿
- 身体反应

### 特效模板

参考视频可只承担：
- 粒子
- 能量
- 变形节奏
- 转场
- 材质变化

## 2. 一个素材一个主职责

不要写：
“参考@视频1的人物、场景、动作、运镜、色调、节奏、特效，但人物还是@图片1，场景还是@图片2。”

这会制造冲突。

改成：
“人物身份严格使用@图片1，固定场景使用@图片2；@视频1只参考动作节奏和摄影机环绕路径，不继承其中人物、服装与背景。”

## 3. 复杂任务使用主次参考

示例：

- 主参考：@图片1人物身份
- 次参考：@图片2服装细节
- 场景：@图片3
- 动作：@视频1

在 Prompt 开头一次性说清。

## 4. 多人物绑定

永远使用固定称呼：

- @图片1 = 角色A
- @图片2 = 角色B

之后只写“角色A/角色B”。

避免“左边的人”“这个角色”“图中的男生”不断变化。

## 5. 使用对象 vs 参考对象

“使用”意味着画面里出现该素材主体。

“参考”意味着迁移某种属性。

必须明确：
- 使用@图片1中的角色
- 参考@视频1的动作

不要写“参考@图片1的人物”后又希望人物100%作为主角出现，容易产生角色漂移。

## 6. 参考视频拆维度

遇到参考视频先问自己：用户真正看中什么？

- 动作？
- 表演？
- 镜头？
- 节奏？
- 特效？
- 转场？
- 声音？

只写最相关的1–3项。

## 7. 一镜到底 + 多参考图

多图不是要切成多镜头。

如果用户要求一镜到底：
- 图1可作为起始区域
- 图2作为中途区域
- 图3作为终点区域

Prompt 明确摄影机连续运动经过这些空间，不切镜。

## 8. 参考图背景隔离

最常见错误之一：人物参考图自带背景，模型把它混入场景。

必须写：
“只使用@图片1的人物外貌与服装，不使用@图片1背景；全程场景严格采用@图片2。”

## 9. 参考优先级

当同一属性有多个素材冲突：

1. 用户明确指定的素材
2. 专门承担该属性的素材
3. 主人物/主场景参考
4. 其他参考只作辅助

不要让模型自己猜。
