## Seedance 2.0 核心能力

官方发布说明强调：

- 统一多模态音视频联合生成
- 支持文字、图片、视频、音频输入
- 全能参考可参考构图、人物、动作、运镜、特效、声音等
- 复杂运动、多主体交互、物理准确性和一致性增强
- 支持可控的视频延长、视频编辑
- 支持最长15秒高质量多镜头音视频输出

## 全能参考参数

即梦使用手册给出的参数：

- 图片：最多9张
- 视频：最多3个，参考视频总时长不超过15秒
- 音频：最多3个，参考音频总时长不超过15秒
- 混合输入总文件数：最多12个
- Seedance 2.0生成时长：4–15秒

这些是能力上限，不意味着每次都应该塞满素材。

## @素材机制

全能参考模式使用 `@素材名` 指明具体用途。

典型职责：

- `@图片1`：人物身份 / 构图 / 场景 / 道具 / 风格
- `@视频1`：动作 / 运镜 / 节奏 / 特效 / 转场 / 声音
- `@音频1`：配音 / 音色 / 节奏 / 声音氛围

核心规则：**明确是“使用对象”还是“参考对象”。**

例如：

- “使用@图片1中的角色，场景采用@图片2”
- “角色身份严格参考@图片1，只参考@视频1的动作节奏和运镜，不继承@视频1中的人物与场景”

## 官方手册体现出的典型能力

### 1. 人物与场景一致性

可通过人物图、场景图等参考维持脸、服装、场景风格等一致。

### 2. 动作与运镜复刻

可让用户角色执行参考视频中的动作，同时参考其镜头变化。

### 3. 复杂特效 / 创意形式复刻

参考视频可以承担粒子、转场、广告片、电影片段等“演绎方式”的模板职责。

### 4. 剧情补全

可以根据分镜图、参考素材和文本指令补全短剧情，但专业创作时仍应明确主要动作和叙事节点，避免完全放任模型。

### 5. 一镜到底

官方示例支持用多张场景/分镜图结合文字，生成连续追踪镜头。设计时要明确镜头路径和空间转移。

### 6. 情绪演绎

可参考视频中的动作、表情和情绪变化，将情绪演绎迁移到指定角色。

### 7. 视频延长

如果延长已有视频，生成时长指“新增部分时长”。Seedance 2.0新增部分仍按≤15秒处理。

### 8. 定向编辑

可把已有视频作为输入，要求只替换人物、调整动作、增加/删减内容等。提示词应明确“改变什么、保留什么”。

## 对本 Skill 的直接约束

1. 默认使用“全能参考”而不是普通纯文本思维。
2. 多素材时必须先绑定职责。
3. 不把所有参考维度混成一句“全部参考”。
4. 参考视频优先作为动作、运镜、节奏、情绪或特效模板。
5. 参考图优先作为人物、场景、服装、道具与构图锚点。
6. 生成长度默认≤15秒。
