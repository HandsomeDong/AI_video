# 专业生成提示词细化标准

当用户要求“专业一点”“细节更多”“导演级”“完整提示词”，或任务包含连续剧情、复杂表演、多人物对峙时读取。

目标是把剧情转译成模型能够执行的视听调度，不是增加空泛形容词。细节必须服务身份稳定、空间清楚、动作完成、情绪可见或段间连续。

## 1. 场景必须可以被摄影机定位

没有专门场景参考图时，先建立少量稳定锚点：

- 空间类型与大致纵深，例如狭长走廊、挑高客厅、圆形控制舱
- 3—5个会影响构图或动作的固定物，例如门、沙发、茶几、立柱、控制台
- 主要材质，例如深色石材、拉丝金属、透明防爆玻璃、旧木柜台
- 时间与主光方向，例如窗外冷色月光从画面左后方进入，室内暖灯从右侧补光
- 会运动的环境元素，例如警报扫光、烟尘、雨水、列车窗外运动视差

不要罗列与动作无关的装饰。多段复用同一地点时，固定空间布局、主光方向和标志物位置；环境变化只能来自剧情。

## 2. 人物调度要写成空间关系

每段开头明确：

- 谁在前景、中景、后景
- 谁站、坐、跪、倒地
- 面朝哪里，视线看谁或看什么
- 人物之间大致距离
- 关键道具在谁手里或空间哪个位置

权力关系用站位呈现：强者通常稳定、占据中心或较高位置；弱者被门框、家具或前景遮挡，或需要主动跨越距离。

## 3. 动作要有身体力学

复杂或关键动作按以下顺序写：

1. 动作意图
2. 发力部位与重心移动
3. 接触点
4. 对方或物体产生的阻力
5. 惯性与衣物、头发、道具的跟随反应
6. 动作完成后的稳定姿态

例如不要只写“她抱紧他”，而要写“她一只手托住后颈、另一只手收紧背部，把他的上半身拉近胸口；他失去支撑的手臂随重力垂落，衣袖与身体产生延迟摆动”。

普通说话场景不必逐块描述肌肉，但手、视线、呼吸、脚步和道具必须具有因果。

## 4. 表情要体现理解过程

不要只写情绪名称。按实际节奏选择3—5个可见节点：

**听见/看见 → 停住原动作 → 眼神寻找或锁定信息 → 呼吸和身体先变化 → 眉眼/嘴角出现微表情 → 压住或释放情绪 → 台词/行动。**

常用细节：

- 瞳孔与视线焦点变化
- 眨眼频率、眼眶积泪而非瞬间流泪
- 下颌绷紧、嘴唇发抖或抿住
- 吸气中断、吞咽、呼气变短
- 手指收紧、肩膀下沉、脚步迟疑

表演强度要分层。若结尾需要崩溃，前面必须先有控制和失控前兆。

## 5. 运镜必须具备起点、动机与终点

每个核心镜头至少明确：

- 起始景别与机位高度
- 主体在画面中的位置
- 摄影机是固定、横移、推进、后拉、升降还是跟随
- 运动由哪个动作或信息触发
- 焦点从谁/什么转移到谁/什么
- 结束时的景别、构图和剧情落点

只有当焦段影响空间关系时才写焦段范围：

- 24—35mm：展示空间、人物距离和灾难规模
- 40—65mm：自然对话、双人关系和缓慢推进
- 70—100mm：压缩空间、捕捉微表情和道具特写

不要同一时刻要求互相冲突的摄影机动作。短段落通常只需要一个核心运镜，其他镜头以固定机位或简单切换配合。

## 6. 光线、材质与气氛服务剧情

写清光的来源和作用：

- 主光塑造人物身份与时间
- 轮廓光分离主体和背景
- 实景光源提供可信来源
- 警报、投影、车窗等动态光只在剧情触发时变化

材质要有光学和物理反馈，例如玻璃反射、金属冷光、石材脚步回声、布料受风、杯子落地碎裂。不要把所有东西同时写成发光、反光或粒子化。

## 7. 声音按层级编排

优先级通常为：关键对白 → 与动作同步的声音 → 环境底噪 → 特效声。

写清哪些声音在对白时降低，哪些声音承担转场或结尾。无背景音乐时，不要用环境声持续抢对白。

## 8. 连续性与结束构图

每段最后明确：

- 人物位置、姿态、朝向和情绪
- 道具归属与状态
- 场景破坏、光线和门窗状态
- 最后画面聚焦的主体

若下一段在同一场景，结束构图应能成为下一段的开头；若跨场景，选择关门、遮挡、白闪、黑屏、动作完成或声音桥等明确切点。

## 9. 时间轴必须承载执行细节

前置的场景、表演和摄影说明只是全局约束，不能代替时间轴。每个时间区间要说明“此刻实际看见和听见什么”，根据情节至少写清：

1. **镜头状态**：起始景别、人物在画面的位置、摄影机是否移动、焦点落在哪里。
2. **动作过程**：谁先动、重心如何变化、手脚接触什么、物体如何受力、动作在哪里完成。
3. **表情过程**：人物看见或听见什么，先停止哪个动作，视线和呼吸如何变化，台词前后出现什么微表情。
4. **环境反馈**：当时的光扫过哪里，门、玻璃、烟尘、衣物、头发、杯子、机械或屏幕如何响应动作。
5. **声音层级**：对白出现时哪些底噪降低，哪个动作声承担停顿、转折或结尾。

时间轴细节应嵌入具体秒段，而不是在时间轴前列出一遍后只写“人物说话”。例如：

较弱：

> 3—7秒：他很委屈地说：“你没来哄我。”镜头推进。

专业：

> 3—7秒：50mm双人近景继续向前推进约四十厘米，焦点从她绷紧的下颌移到他的绿色眼睛。警报红光扫过时，他先被强光刺得眨眼，随后重新锁住她的脸；吸气只完成一半便转为短促呼气，嘴角勉强抬起，用几乎听不见的埋怨说：“你一直没来哄我……”对白出现时核心轰鸣降为低频底噪，她托住他后颈的手指随台词逐渐收紧。

不要为了详细而在一个秒段塞入新的剧情事件。只细化已有动作的可见过程、情绪因果、摄影机和环境响应。

## 10. 细节密度控制

只写模型需要执行的可见或可听信息。删除：

- 与镜头无关的世界观解释
- 同义形容词叠加
- 不会进入画面的陈设
- 没有动作后果的特效
- 每秒都切换景别、镜头和情绪的过度调度

专业完整版不是越长越好，而是每个重要细节都有职责。

## 11. 完整版 Prompt 自检

- 场景是否能画出平面关系？
- 人物起始位置是否不会互相矛盾？
- 动作是否能看出发力、接触和结果？
- 表情是否有理解与变化过程？
- 摄影机是否知道从哪里到哪里？
- 光线和动态环境是否有来源？
- 对白是否有可表演的语气、停顿和反应空间？
- 最后一帧是否明确且能承担结算或接力？
- 每个时间区间是否独立写清镜头、动作、表情、环境反馈和声音重点？
