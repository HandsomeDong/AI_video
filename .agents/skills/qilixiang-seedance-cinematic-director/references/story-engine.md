# 电影级短视频剧情引擎

## 1. 先找“戏”，再找“镜头”

短视频剧情的最小单位不是镜头，而是变化。

一段必须至少发生一种变化：
- 权力变化
- 信息变化
- 情绪变化
- 空间变化
- 危险变化
- 目标变化

如果15秒过去什么都没变，剧情通常不成立。

## 2. 一句话命题

先写一句内部命题：

“一个___的人，为了___，却因为___，最终___。”

这句话不一定给用户看，但必须帮助判断段落是否偏题。

## 3. 前3秒钩子

优先：
- 冲突动作
- 反常视觉
- 极强身份关系
- 明确悬念
- 视觉尺度

不要：
- 角色走进房间3秒
- 城市大全景3秒
- 缓慢介绍背景

除非它本身就是奇观。

## 4. 微型三幕

15秒也可以有三幕：

### 建立
观众立刻知道“发生了什么”。

### 升级
事情变得更难、更怪、更危险或更尴尬。

### 支付
用反转、高潮、笑点、决定性动作结算前面的铺垫。

## 5. 搞笑升级链

推荐：

现实逻辑成立
→ 小异常
→ 人物认真解决
→ 解决方式更荒谬
→ 规模升级
→ 最后一刀

### 喜剧关键

荒谬事情发生时，角色不一定要知道自己很搞笑。

一本正经通常比“全员搞怪”更好笑。

## 6. 黑镜式脑洞

结构：

便利出现
→ 主角获得好处
→ 依赖
→ 边界被突破
→ 主角意识到代价
→ 冷酷或荒诞结局

不要一开始就告诉观众科技有问题。

## 7. 视觉优先

AI视频特别适合：
- 巨型尺度
- 超现实物理
- 角色身份反差
- 环境变化
- 变身
- 极端空间关系

能用画面讲的不要用台词讲。

## 8. 台词

短、口语、能演。

尽量：
- 一次一句
- 一句表达一个意图
- 角色说话时给动作

不要15秒里让同一角色讲100字说明文。

## 9. 结尾

优先级：
1. 视觉反转
2. 人物反应
3. 极短补刀台词
4. 黑屏/动作冲击

不要在最强笑点之后再拖3秒解释。
