## 单段内容

1. 生成时长（4—15秒）
2. @素材职责
3. 独立场景与人物起始位置
4. 时间轴动作与表演
5. 镜头设计
6. 对白与声音
7. 段尾接力状态
8. 必要避免项

专业增强版还包含：场景空间和固定物、材质与主光方向、人物起始调度、身体重心与接触反馈、微表情反应链、摄影机起终点与焦点变化。

每一个时间区间内部都会再次写明当下镜头、人物动作、微表情与反应链、场景物理反馈、对白语气和声音层次；前置的场景与表演总述不能替代时间轴中的秒级执行细节。

每个提示词都会完整重述本段的场景、人物站位和道具状态，不使用“延续上一段”“同一场景”或“复用第X段布局”等跨段引用。

跨段固定使用同一人物素材称呼：

- `@图片1`＝豆总
- `@图片2`＝奶蛙
- `@图片3`＝袋鼠

三张角色图只承担人物身份与外形，不继承原图白色背景。没有上传专门场景图时，场景由每段文字提示词独立建立。

## 连续性提醒

- 第一段不出现袋鼠，也不解释时间循环。
- 第二至第八段维持奶蛙的同一只未打开行李箱。
- 戒指顺序：豆总摘下放茶几 → 重新捡起 → 穿在项链上 → 带入控制舱 → 袋鼠封存 → 三十年后交还奶蛙。
- 银灰色档案箱只在第十三段、三十年后的奶茶店首次出现。
- 袋鼠始终没有育儿袋，不能从身体或“口袋”中取放物品。
- 第十七段在奶蛙按下时间核心的瞬间直接黑屏，不展示穿越是否成功。
