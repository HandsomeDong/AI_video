# 示例：15秒荒诞喜剧

## 目标
用正常职业场景建立逻辑，再在最后3秒反转。

## Prompt

视频15秒，真人写实、真实摄影、电影级短剧质感，无字幕、无背景音乐，只保留超市环境声、脚步声和自然对白。

@图片1严格作为男店员角色参考，保持脸、发型、身材和工作服一致，不使用原图背景；@图片2作为女顾客参考；@图片3为固定超市场景，保持货架布局和灯光一致。

0–4秒，中景平视。男店员站在货架旁认真整理商品，女顾客走到他面前，直接问一种商品。男店员立刻进入职业状态，抬头礼貌回答。

4–9秒，镜头轻微推进。女顾客继续一本正经提出越来越奇怪的要求，男店员先思考，再认真在货架上寻找，完全没有意识到话里的双关。

9–12秒，近景。女顾客看着男店员，用一句极短的台词完成真正的包袱。男店员先僵住半秒，眼睛微微睁大。

12–15秒，特写。男店员视线躲开，脸逐渐变红，嘴角想压住却压不住，身体轻微扭捏，嘴上小声抗拒但明显被逗开心。镜头停在他的反应上结束。

保持人物身份和场景一致，不增加围观群众，不出现字幕或背景音乐，不提前用夸张表演剧透笑点。
