# 表现形式、封面与双语字幕

本参考用于同一故事在真人与动画之间转换、为短剧制作不同比例封面，以及把中文对白转换成英文字幕。不要在转换过程中自动增加新剧情。

## 1. 真人版与动画版分流

### 真人写实

- 核心演员应呈现明确的成年人年龄感。
- 强调真实皮肤、头发、布料、重量、惯性、接触和空间反馈。
- 表演通常更克制，通过呼吸、眼神、下颌、肩膀、手指和重心变化表达情绪。
- 现实题材中的饮酒、酒店、亲密关系等情节，要让人物意识状态、行动能力、边界和自主决定清楚可信。
- 禁止动画感、塑料皮肤和过度网红滤镜，除非用户明确指定。

### 动画、CG或拟人角色

- 优先保证造型、材质、比例和服装稳定。
- 表情可以提高可读性，但不默认夸张成卡通闹剧。
- 接触动作仍要有重量、惯性、衣料或表面反馈。
- 避免多肢体、五官漂移、角色复制和材质突变。

从一种形式转换到另一种形式时，只改变表现介质和表演尺度；用户已经确定的故事功能、关系和关键动作保持原意，除非用户同时要求改写。

## 2. 多比例封面

同一项目需要多个比例时，把它们视为独立构图任务：

- 3:4竖版优先使用上下层级、前后景和三角构图，主体面部落在移动端安全区域。
- 4:3横版优先使用左右关系、人物间距和环境纵深。
- 不从一个比例机械裁切出另一个比例。
- 关系和核心情绪应在缩略图尺寸下一眼可读。
- 反转故事可以用隐秘对视、视线错位或克制微表情暗示悬念，但不要直接展示最终拥抱、共谋证据或结局动作。
- 默认不添加标题、字幕、Logo或水印；用户明确要求文字时再设计排版和安全区。
- 修改封面中的单一问题时，保持已确认的构图、背景、光线和其他人物不变，并默认另存新版本。

## 3. 中英双语字幕

英文字幕以自然口语和屏幕阅读为目标：

- 先判断人物关系、语气和潜台词，再选择英文表达。
- 优先简短自然，不逐字复制中文语序。
- 保留质问、试探、委屈、决绝或暧昧等语气差异。
- 同一称谓和关键概念在全片保持一致。
- 被角色打断的句子用破折号或省略号保留中断感。
- 中文被拆成多个表演节拍时，英文也按节拍拆开，不强行合成一整句。
- 避免超过画面可读时间的长句；必要时在不损失含义的前提下压缩。

分段反转台词可以保持句法接力，例如：

- “这下……” → “Now…”
- “我们终于……” → “We can finally…”
- “能在一起了。” → “be together.”

交付时按“中文原句 → 英文字幕”逐条对应，方便直接录入剪辑软件。
