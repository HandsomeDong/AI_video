# AI 视频剧本与提示词创作

本工作区用于整理 AI 视频的剧本、角色设定、分段提示词和版本记录，不保存生成图片、视频等素材文件。

## 目录

- `创作项目/项目索引.md`：全部剧本项目与当前进度
- `创作项目/001-她骗他是为了让他活在没有她的未来/`：当前第一个剧本项目
- `.agents/skills/qilixiang-seedance-cinematic-director/`：短视频剧情、导演与提示词创作 Skill

每个剧本使用独立编号目录。标题尚未确定时可先使用 `编号-未定名`，剧情方向稳定后再改正式标题。

当前项目已完成17段剧情及专业增强版生成提示词，后续可逐段生成并根据实际成片继续调整。
