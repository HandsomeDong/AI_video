# Seedance 2.0 Prompt 编写规范

## 1. 自然语言优先

Seedance 2.0能够理解自然语言和多模态参考。

Prompt 重点是：
- 任务明确
- 参考绑定明确
- 动作顺序明确
- 镜头明确

不是关键词数量。

## 2. 标准顺序

### 第一段：总规则

- 时长
- 真人写实/风格
- 无字幕/无背景音乐

### 第二段：参考素材职责

- @图片1人物
- @图片2场景
- @视频1动作/运镜

### 第三段：时间轴

用动作节点拆分。

### 第四段：关键约束

只写最容易翻车的内容。

## 3. 时间轴语言

推荐：

“0–3秒：……”
“3–8秒：……”
“8–12秒：……”
“12–15秒：……”

时间区间不是强制切镜。

一镜到底必须明确“全程同一连续镜头”。

## 4. 描述动作链

好：
“男人听见身后声音后停步，先回头，再转身，看到来人后下意识后退半步。”

差：
“男人很惊讶地转身后退，电影感。”

## 5. 减少冲突

避免同时：
- 固定镜头 + 大幅环绕
- 慢动作 + 极快实时追逐且无转场
- 人物静止 + 高速奔跑

## 6. 避免词不要写成几十项负面词库

只限制最关键问题，例如：
- 不换脸
- 不换服装
- 不改变固定场景
- 不突然闪光变身

## 7. 参考视频

最有效结构：

“@视频1只参考XX和XX，不继承人物、服装和场景。”

## 8. 画面信息过载

15秒内尽量避免同时出现：
- 3个以上复杂人物动作链
- 2场长对白
- 多次地点切换
- 多种特效体系
- 复杂变身 + 打斗 + 台词 + 大运镜全部叠加

必要时拆段。
