# 出片质量检查

## Seedance适配

- [ ] 单段≤15秒，除非用户明确30秒
- [ ] @素材名都明确
- [ ] 参考素材职责不冲突
- [ ] 复杂动作数量合理

## 导演

- [ ] 前3秒有事件/钩子
- [ ] 一段只有一个主戏剧功能
- [ ] 每个运镜有动机
- [ ] 角色空间关系清楚
- [ ] 最后有落点

## 一致性

- [ ] 人物身份一致
- [ ] 服装一致
- [ ] 场景一致
- [ ] 道具连续
- [ ] 破坏/天气/光线连续

## 表演

- [ ] 情绪有反应链
- [ ] 关键反应有时间
- [ ] 不全员同强度夸张

## 声音

- [ ] 默认无字幕
- [ ] 默认无背景音乐
- [ ] 对白长度可在时长内自然说完
- [ ] 必要动作声/环境声明确

## Prompt

- [ ] 可直接复制
- [ ] 没有“继续上一段”类模糊依赖
- [ ] 没堆重复形容词
- [ ] 没有互相矛盾的镜头命令
