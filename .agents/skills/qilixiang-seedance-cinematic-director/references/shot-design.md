# 电影级分镜与运镜写法

## 基本格式

每个镜头写：

- 时间
- 景别
- 机位
- 主体位置
- 动作
- 表演
- 摄影机运动
- 镜头结束画面

## 推进

写清：
“从中景缓慢推进到近景”
而不是只写“镜头推进”。

## 拉远

适合：
- 揭示灾难规模
- 揭示角色孤立
- 从细节切到奇观

## 环绕

必须写4项：
1. 起点
2. 绕行方向/弧线
3. 中间主体关系
4. 终点

## 背后视角

适合建立：
- 对峙
- POV式代入
- 巨型目标

写清前景人物背影和远处目标。

## POV

如果用户要求第一视角：
- 摄影机就是角色眼睛
- 适度自然身体晃动
- 必要时画面边缘能看到手/前爪/身体
- 机位高度符合角色身高/物种

## 低机位

不是单纯“相机很低”。

写：
- 相机距地面高度
- 镜头向上仰
- 主体腿部/身体透视
- 背景结构如何形成压迫

## 高速移动

稳定场景 + 极快主体通常比摄影机一起乱跑更能体现速度。

可用：
- 突然启动
- 残影
- 急停
- 远近瞬间变化
- 地面雾气/尘埃受力

停止瞬间人物必须恢复清晰。

## 变身

重点是过程可见：

人物本体
→ 结构生成
→ 沿身体蔓延
→ 折叠/旋转/咬合
→ 局部锁定
→ 头部闭合
→ 能量启动

禁止：
- 闪光后直接变好
- 第二套机甲从外部套上
- 多出第二个人

## 一镜到底

不要写“镜头A、镜头B”。

改写为同一摄影机内的：
- 0–3s 位置/动作
- 3–7s 摄影机继续移动
- 7–12s 主体交接
- 12–15s 到达终点
