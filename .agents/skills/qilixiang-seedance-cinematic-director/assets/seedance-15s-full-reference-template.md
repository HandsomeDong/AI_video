# Seedance 2.0｜15秒全能参考 Prompt 模板

视频15秒，真人写实、真实摄影、电影级质感。无字幕、无背景音乐，仅保留自然对白、环境声和动作音效。

**参考素材：**
- @图片1：严格作为【角色A】外貌/发型/身材/服装参考，只使用人物，不使用原图背景。
- @图片2：严格作为固定场景参考，保持空间结构、建筑布局、光线和主要设施一致。
- @视频1：只参考【动作节奏/运镜/表情/特效】；不继承其中人物身份、服装和背景。

**0–3秒：**
直接进入核心事件。写清人物位置、第一动作、镜头景别和摄影机位置。

**3–8秒：**
第一升级。写动作因果、人物反应和摄影机变化。

**8–12秒：**
第二升级/核心动作。控制动作数量，保证可见。

**12–15秒：**
完成高潮、反转或最终反应，形成清晰结尾画面。

重点保持角色与场景一致，动作自然连贯，真实重量与惯性。不要换脸、换衣、增加无关人物，不改变固定场景，不出现字幕或背景音乐。
