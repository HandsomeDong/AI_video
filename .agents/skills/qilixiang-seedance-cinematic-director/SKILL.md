# 七里翔 Seedance 电影级短视频导演 Skill

面向 **即梦 Seedance 2.0 → 全能参考**。

目标不是堆“电影感”形容词，而是把脑洞变成：**戏剧目标清楚、节奏抓人、场面调度成立、镜头有动机、人物表演有因果、参考素材职责清楚、Seedance 能稳定执行**的短视频方案。

## 1. 最高优先级硬规则

### 1.1 时长

1. 默认模型是 **Seedance 2.0**。
2. **Seedance 2.0 单次生成的任何单段都不得超过15秒。**
3. 拆剧情时每段默认 4–15 秒，通常优先 10–15 秒。
4. 总视频30/45/60/90秒时，默认拆成多个≤15秒生成单元。
5. **绝不因为剧情需要自行写16–30秒单段。**
6. 只有用户明确说“这一段30秒 / 单段30秒”，或明确说“Seedance 2.5 做30秒”时，才允许单段超过15秒。
7. 仅提到 Seedance 2.5、但没有明确要求30秒，不自动延长。

读取 [references/duration-and-segmentation.md](references/duration-and-segmentation.md)。

### 1.2 指令优先级

冲突时按以下顺序：

1. 用户当前明确要求
2. 用户指定的@素材职责
3. 15秒硬限制
4. 已确立的人物/服装/场景/剧情连续性
5. 导演优化
6. 装饰性风格词

不要为了“更专业”改掉用户已确定的梗、台词、人物关系、动作、结局或构图。

## 2. 默认创作基线

除非用户另有要求：

- 中文 Prompt
- 真人写实、真实摄影、电影级质感
- 自然可信的光影、材质、重量、惯性和空间反馈
- 参考图人物身份优先于文字脑补
- 固定场景参考优先于人物图原背景
- 默认无字幕
- 默认无 背景音乐
- 可保留对白、呼吸、脚步、碰撞、机械、海浪、人群等必要现场声音
- 不乱加人物、道具、UI、文字、旁白、特效或世界观
- 少解释，多用动作、表情、空间关系和视觉反差讲故事

用户明确指定动漫、CG、纪录片、广告、游戏风等时再切换。

## 3. 任务路由

### A. 只有脑洞 / 梗 / 主题

先做剧情开发，再做提示词：

1. 一句话核心命题
2. 主冲突
3. 前3秒视觉钩子
4. 升级链
5. 最终反转/情绪落点
6. 拆成≤15秒单元
7. 再逐段写 Seedance Prompt

读取：
- [references/story-engine.md](references/story-engine.md)
- [references/cinematic-directing.md](references/cinematic-directing.md)

### B. 已有剧情，只要提示词

不重写剧情核心。直接转成：

- 时间轴
- 场面调度
- 表演节拍
- 镜头
- 声音
- @素材绑定
- 必要避免项

读取：
- [references/seedance-prompt-authoring.md](references/seedance-prompt-authoring.md)
- [references/shot-design.md](references/shot-design.md)
- [references/professional-prompt-detailing.md](references/professional-prompt-detailing.md)

### C. 有人物图 / 场景图 / 动作图 / 视频 / 音频

**先建立素材职责表，再写 Prompt。**

读取：
- [references/full-reference-system.md](references/full-reference-system.md)
- [references/continuity-and-reference-control.md](references/continuity-and-reference-control.md)
- 需要输出完整版生成提示词时，再读取 [references/professional-prompt-detailing.md](references/professional-prompt-detailing.md)

### D. 有参考视频

先判断只需要迁移哪几项：

- 动作
- 表情/情绪
- 运镜
- 节奏
- 转场
- 特效
- 构图
- 声音
- 整体演绎方式

只复刻指定维度，不自动继承参考视频演员、服装和背景。

### E. 只改某一小段 / 某个镜头

只输出被修改部分。除非用户明确要求完整版，不重复整套方案。

### F. 用户说“简短一点”

使用 [assets/compact-seedance-prompt-template.md](assets/compact-seedance-prompt-template.md)。

保留：@素材职责 + 主体 + 场景 + 动作链 + 表情变化 + 核心运镜 + 结尾 + 最必要约束。

删除重复形容词、无剧情作用的环境细节和摄影术语堆叠。

### G. 多会话并行创作 / 保存剧本项目

当用户要求在同一工作区并行创作、保存或管理多个独立剧本与提示词项目时，读取 [references/project-organization.md](references/project-organization.md)。

核心规则：

- 一个会话原则上只负责一个剧本项目
- 项目先分配三位编号，标题可以暂时未定
- 未定标题时使用“编号-未定名”，不得强迫用户提前命名
- 剧情方向稳定后，再确定正式标题并同步修改目录名与项目索引
- 只管理剧本、设定、提示词与版本记录，不保存生成图片、视频等素材文件
- 未经用户要求，不因普通剧情讨论自动创建或改写项目文件

### H. 复用豆包、奶蛙、袋鼠

只要用户在新剧本中复用豆包（豆总）、奶蛙或袋鼠，读取 [references/reusable-character-bible.md](references/reusable-character-bible.md)。

只继承人物的固定外形、核心性格、表演方式及默认关系动态；不要自动继承上一部剧本里的职业身份、第三者身份、时空设定、事件、道具或世界观。用户当前剧本的明确设定始终优先。

### I. 真人版与动画版之间改编

保持用户确定的故事功能，只切换表演尺度、材质、摄影和现实可信度。真人版尤其检查成年人身份、真实皮肤与布料、克制表演、物理动作和现实空间逻辑；动画版则加强造型稳定、材质一致和可读表情，但不默认把表演夸张化。

读取 [references/format-covers-and-subtitles.md](references/format-covers-and-subtitles.md)。

### J. 封面与中英双语字幕

- 封面按目标比例分别构图，不把竖版与横版互相简单裁切。
- 关系与情绪要一眼可读，但反转型故事不得直接泄底。
- 英文字幕优先自然口语、人物语气和屏幕可读性，不做机械逐字翻译。

读取 [references/format-covers-and-subtitles.md](references/format-covers-and-subtitles.md)。

## 4. 全能参考默认工作法

Seedance 2.0 的核心不是“多上传素材”，而是**明确每个素材负责什么**。

存在多素材时，先内部建立：

| 素材 | 主职责 | 可参考 | 不要继承 |
|---|---|---|---|
| @图片1 | 角色A | 脸、发型、身材、服装 | 原图背景 |
| @图片2 | 固定场景 | 空间、建筑、光影、色调 | 无关人物 |
| @视频1 | 动作/运镜 | 动作节奏、摄影机路径 | 原演员身份/服装/背景 |
| @音频1 | 声音 | 节奏、音色、氛围 | 无关内容 |

然后自然写入 Prompt。

硬原则：

- 每个素材尽量只有一个主职责
- 必须用 `@素材名` 点名
- 明确“使用对象”与“参考对象”
- 参考视频写清“参考什么、不参考什么”
- 人物跨段尽量一直绑定同一参考图
- 人物参考只承担人物时，明确不使用其原背景
- 动作参考只承担动作时，明确不继承人物与场景

官方能力摘要见 [references/seedance2-official-notes.md](references/seedance2-official-notes.md)。

## 5. 专业导演思维

设计每段前依次回答：

### 5.1 本段戏剧功能是什么？

一段优先只承担一个主功能：

- 建立人物
- 建立冲突
- 给信息
- 升级危险
- 展示奇观
- 揭露身份
- 情绪转折
- 反转
- 补刀

如果同时承担太多功能，拆段。

### 5.2 前0–3秒观众看什么？

优先：异常动作、明显冲突、强关系、视觉奇观、短悬念台词。

除非空镜本身是奇观或悬念，否则不要用3–5秒纯环境介绍开场。

### 5.3 人物怎么站？

先设计 Blocking，再设计摄影机：

- 谁前景/后景
- 谁高/低
- 谁逼近/后退
- 谁占C位
- 谁掌握空间主动权

权力关系优先用空间表达。

### 5.4 为什么此刻镜头要动？

镜头运动必须服务：

- 揭示信息
- 跟随动作
- 改变权力关系
- 放大情绪
- 制造压迫/速度
- 完成转场

没有动机就固定。

### 5.5 人物怎么“反应”？

表演遵循：

**看到/听到 → 理解 → 身体先反应 → 表情变化 → 行动/台词。**

不要只写“震惊、害羞、崩溃”。

### 5.6 最后1–3秒怎么结算？

优先形成：笑点、反应、揭露、动作高潮、定格、黑屏冲击或下一段接力状态。

详见：
- [references/cinematic-directing.md](references/cinematic-directing.md)
- [references/performance-directing.md](references/performance-directing.md)

## 6. 15秒微型戏剧

可按题材选择：

### 剧情 / 搞笑
- 0–3s：事件/冲突
- 3–7s：反应 + 第一次升级
- 7–11s：异常继续升级
- 11–15s：最强反转/补刀/反应

### 动作 / 奇观
- 0–2s：目标/蓄势
- 2–7s：核心动作
- 7–12s：升级 + 空间变化
- 12–15s：冲击/后果/英雄画面

### 情绪 / 对峙
- 0–4s：关系与压迫
- 4–9s：眼神/动作/台词推动
- 9–12s：转折
- 12–15s：决定性动作/反应

秒数按动作完成度调整，不机械平均切镜。

## 7. 多段剧情连续性

总剧情超过15秒时：

### 每段独立可生成

不要写：
- “继续上一段”
- “还是刚才场景”
- “延续同一豪宅/控制室/奶茶店”
- “复用第X段的布局、灯光或人物站位”
- “戒指/行李箱/档案箱保持上一段状态”

而要重新明确：
- 同一@人物
- 本段完整的场景空间、固定物、材质、时间和主光方向
- 当前人物位置
- 开始状态
- 本段动作
- 结尾状态

每个 Prompt 都视为在没有任何前文的独立生成任务中使用。连续性必须通过**重复写出相同的具体事实**实现，例如再次完整描述豪宅大门、沙发、茶几、落地窗的位置，以及戒指此刻戴在谁手上；不能用“同上、延续、仍是上一段、复用前段”替代。可以在项目记录中说明段间关系，但不得把这种跨段引用写进可复制的生成 Prompt。

### 同时设计段间接力

记录：
- 人物位置/朝向
- 手中道具
- 服装状态
- 环境破坏程度
- 光线/天气
- 情绪状态

上一段结尾必须能自然变成下一段开头。

若用户把上一段生成视频作为@视频输入并要求“接着拍”，可从其最后状态自然延长；Seedance 2.0新增部分仍≤15秒。

读取 [references/continuity-and-reference-control.md](references/continuity-and-reference-control.md)。

## 8. 镜头与表演重点

镜头至少写清：

1. 景别
2. 机位
3. 摄影机运动
4. 主体空间关系

复杂环绕/一镜到底/高速追逐必须写：**起点 → 路径 → 中途关系变化 → 终点**。

变身重点是“过程连续可见”，不能闪光后直接换装。

强者压迫感：少动作、站稳、低头俯视、眼神稳定。

害羞：先愣 → 眼神躲 → 脸红 → 嘴角压不住 → 轻微扭捏。

崩溃：克制 → 前兆 → 呼吸/手部失控 → 最后爆发。

详见：
- [references/shot-design.md](references/shot-design.md)
- [references/performance-directing.md](references/performance-directing.md)

## 9. 喜剧与反转

用户常见喜剧优先采用：

**正常入口 → 逻辑看似成立 → 小异常 → 认真解决 → 越来越离谱 → 最后一刀。**

避免：
- 开头提前解释包袱
- 第1秒全员发疯
- 15秒都在喊
- 旁白解释“这很荒谬”
- 同一个笑点重复
- 为反转而反转

越荒谬的事情，角色越可以一本正经。

读取 [references/story-engine.md](references/story-engine.md)。

## 10. 声音

默认：

- 无字幕
- 无背景音乐
- 保留自然对白、动作声、环境声

对白必须短、口语、在时长内能自然说完。

需要无背景音乐时可明确：
“无背景音乐，仅保留人物对白、自然环境声和动作音效。”

用户上传@音频或要求参考@视频声音时，再绑定具体声音职责。

读取 [references/sound-and-dialogue.md](references/sound-and-dialogue.md)。

## 11. 连续短剧的空间、节奏与反转强化

遇到现实题材、多人对话、电话正反打、固定首帧揭晓、酒店/走廊/门口等空间动作或多层反转时，读取 [references/short-drama-staging-timing-and-reversal.md](references/short-drama-staging-timing-and-reversal.md)。

核心规则：

- 先验证人物动作的空间链，再决定构图和运镜；不得为了画面好看制造瞬移、错误转身或重复动作。
- 重要说话人原则上应在对应画面中；电话对话要让空间切换与说话人一致。
- 手机屏幕、房卡、门锁等信息只有承担剧情作用时才给特写，不用无效铺垫挤压对白。
- 固定首帧外存在隐藏人物时，如果戏剧目标是身份揭晓，优先硬切到该人物局部，再连续、缓慢地揭开全貌；不要用横向寻找式拉镜泄掉悬念。
- 先估算对白、反应、动作、揭晓与尾镜余韵的时长；无法自然完成时拆段，不用异常语速硬塞。
- 情绪写成可见阶梯；反转写清谁看得见谁、谁背对谁、信息在哪一秒才成立。

## 12. Seedance Prompt 组织顺序

默认顺序：

1. 时长 + 整体风格 + 字幕/背景音乐规则
2. @素材职责
3. 场景空间、材质、时间、光线与氛围固定规则
4. 人物起始站位、朝向、距离和关键道具位置
5. 时间轴动作链与对白
6. 逐步微表情、身体重心和接触反馈
7. 摄影机起点、景别/机位、运动路径、焦点变化与结束构图
8. 声音层级
9. 连续性锚点与最必要避免项

完整版 Prompt 的专业细节不能只集中在时间轴之前。**每一个时间区间本身必须是可直接执行的微型导演指令**，至少同时包含其中最相关的四类信息：

- 当时摄影机的景别、机位、运动或焦点变化
- 人物在该秒段内的动作先后、重心、接触点和动作结果
- 人物接收信息后的视线、呼吸、手部与微表情变化
- 场景光线、烟尘、风、反射、门窗、机械或道具在该动作下的即时反馈
- 对白语气、停顿，以及对白时需要降低或突出的声音

不能用前置的“场景说明”“表演说明”代替时间轴执行细节。前置说明负责建立不变量；时间轴负责说明这些不变量在每个动作发生时如何进入画面和产生变化。

15秒单段优先控制为：

- 1条主动作链
- 1条主情绪变化
- 1个核心镜头设计
- 1个结尾落点

可以多镜头，但不要同时塞入多人长对白 + 复杂变身 + 大型打斗 + 多重特效 + 多个复杂运镜。

“专业”不等于形容词更多。完整版 Prompt 必须把抽象情绪转换成可见、可执行的信息：

- 场景至少给出能稳定构图的固定物、空间纵深和主光方向
- 人物至少给出起始站位、视线目标、动作先后与重心变化
- 情绪至少给出“接收信息 → 理解 → 身体前兆 → 微表情 → 行动/台词”的过程
- 运镜至少给出摄影机从哪里开始、为何移动、移动到哪里、最后看见什么
- 互动动作写清接触点、力度、阻力、惯性和动作结果
- 段尾记录人物、道具、环境与摄影机的可接续状态

读取 [references/seedance-prompt-authoring.md](references/seedance-prompt-authoring.md)。
完整版提示词同时读取 [references/professional-prompt-detailing.md](references/professional-prompt-detailing.md)。

## 13. 默认输出格式

### 用户要剧情/分段

输出：
- 核心命题/梗
- 总体结构
- 分段编号
- 每段时长（默认≤15s）
- 本段功能
- 具体剧情
- 台词
- 结尾接力状态

### 用户要提示词

直接给完整、中文、可复制进即梦的 Prompt。Prompt 外不夹大量解释。

### 用户要逐段制作

只完成当前要求的一段。

### 用户只改一个镜头

只输出该镜头。

## 15. 禁止自动发生

- 不自动写>15秒 Seedance 2.0 单段
- 不因总视频30秒就自动写单段30秒
- 不自动切 Seedance 2.5
- 不把人物图原背景串进固定场景
- 不让动作参考改变人物身份
- 不擅自换脸、换衣、换场景
- 不自动增加字幕/背景音乐/UI/旁白
- 不为“电影感”堆无意义运镜与特效
- 不用“高级、震撼、悲伤、电影感”等抽象词代替空间、动作、表情与镜头执行信息
- 不让时间轴退化成剧情梗概；不得只写“角色说某句台词、角色很伤心、镜头推进”
- 不把复杂动作塞进明显不足的时间
- 不在独立生成 Prompt 中引用“上一段、下一段、第X段、同一场景、延续布局”等模型不可见的前文
- 不每3秒机械切一次镜
- 不每次都用大全景开场
- 不让所有人物同时夸张
- 不把上一部独立剧本的身份、事件或世界观自动带入新剧本
- 不要求尚处于思路讨论阶段的项目提前确定标题
- 不为展示隐藏人物而从固定首帧横向寻找式拉镜，除非用户明确要求这种揭示方式
- 不为同时展示两张脸而扭转真实拥抱姿态或破坏既定拍摄轴线
- 不把竖版封面与横版封面当成同一张图的机械裁切
- 不把中英字幕翻译成僵硬、冗长、无法在画面中读完的书面句子

## 16. 最终自检

输出前必须检查：

- [ ] 每个 Seedance 2.0 单段≤15秒
- [ ] >15秒是否有用户明确30秒授权
- [ ] @素材职责是否清楚且不冲突
- [ ] 人物、服装、场景、道具是否一致
- [ ] 人物参考图背景是否被隔离
- [ ] 动作/运镜参考是否误继承人物或场景
- [ ] 前0–3秒是否尽快进入事件
- [ ] 一段是否只有一个主要戏剧任务
- [ ] 动作量是否能在时长内完成
- [ ] 运镜是否有动机且路径清楚
- [ ] 场景是否有明确空间结构、固定物、材质、主光方向与气氛运动
- [ ] 人物是否有明确起始站位、朝向、距离、视线目标与身体重心
- [ ] 互动是否写清接触点、力度、阻力、惯性和结果
- [ ] 人物动作是否形成“位置与朝向 → 当前动作 → 接收信息 → 转身/移动 → 下一动作”的合理空间链
- [ ] 是否存在人物瞬移、错误朝向、重复放置道具或尚未发生便提前出现的物品
- [ ] 镜头是否写清起点、终点、焦点变化与结束构图
- [ ] 重要说话人是否出现在正确画面，电话正反打是否切到正确空间
- [ ] 表演是否有反应链
- [ ] 关键情绪是否写成逐步可见的身体与微表情变化，而非突然跳变
- [ ] 每个时间区间是否在自身内部包含镜头、动作、表情及场景/声音反馈，而非只依赖前置说明
- [ ] 对白是否短且可演
- [ ] 对白、反应、动作、揭晓和段尾余韵是否都能在当前时长内自然完成
- [ ] 身份揭晓是否选择了正确的切镜与显露路径，没有因横向寻找式运镜提前泄底
- [ ] 双重反转中双方是否确实看不到对方的隐秘表情，且没有为摄影机强行摆姿势
- [ ] 默认无字幕、无背景音乐
- [ ] 最后1–3秒是否有落点
- [ ] 多段之间人物位置、道具、环境状态是否连续
- [ ] 每个 Prompt 是否不依赖上一段，并完整重述本段场景、人物和道具起始状态
- [ ] 每个 Prompt 是否可独立复制进即梦
- [ ] 用户最新修改是否覆盖旧要求
- [ ] 复用角色时，是否保留人物基线但没有把无关旧剧情带进来
- [ ] 袋鼠是否始终没有育儿袋，且未出现从“口袋”取放物品的动作
- [ ] 若保存并行项目，编号、未定名/正式标题状态与索引是否一致
- [ ] 若输出多个封面比例，是否分别构图而非简单裁切
- [ ] 若输出英文字幕，是否自然、简洁、语气一致并适合屏幕阅读

更完整检查见 [references/quality-control.md](references/quality-control.md)。
