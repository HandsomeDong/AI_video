# AI 视频剧本项目索引

## 使用约定

- 一部剧本使用一个独立编号目录。
- 一个 Codex 会话只负责一个剧本目录，避免并行创作时互相覆盖。
- `剧情/剧情总稿-v1.md` 保存当前确认版；较大改版按 v2、v3 另存。
- `设定/核心设定.md` 保存人物、世界观、道具与连续性硬规则。
- `提示词/` 按生成段落分别保存 Seedance 提示词。
- 素材图片和生成视频不存入本项目，只在提示词中记录其职责与引用名称。
