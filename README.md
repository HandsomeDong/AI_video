## 中文

本项目用于整理 AI 视频的剧本、角色设定、分段提示词和版本记录，并提供一套用于短视频剧情、导演设计与生成提示词创作的 Codex Skill。生成图片、视频及私人创作目录不提交到仓库。

### 目录

- [`创作项目_example/项目索引.md`](创作项目_example/项目索引.md)：示例剧本项目与制作进度
- [`创作项目_example/001-她骗他是为了让他活在没有她的未来/`](创作项目_example/001-她骗他是为了让他活在没有她的未来/)：完整剧本、设定与17段专业生成提示词示例
- [`.agents/skills/qilixiang-seedance-cinematic-director/`](.agents/skills/qilixiang-seedance-cinematic-director/)：短视频剧情、导演与提示词创作 Skill

每个剧本使用独立编号目录。标题尚未确定时可先使用 `编号-未定名`，剧情方向稳定后再改为正式标题。

## English

This repository organizes AI video scripts, character profiles, segmented generation prompts, and revision history. It also includes a Codex Skill for short-form storytelling, cinematic direction, and professional video prompt creation. Generated media and private working projects are excluded from the repository.

### Contents

- [`创作项目_example/项目索引.md`](创作项目_example/项目索引.md): example project index and production status
- [`创作项目_example/001-她骗他是为了让他活在没有她的未来/`](创作项目_example/001-她骗他是为了让他活在没有她的未来/): a complete example containing the script, story rules, and 17 professional generation prompts
- [`.agents/skills/qilixiang-seedance-cinematic-director/`](.agents/skills/qilixiang-seedance-cinematic-director/): Codex Skill for short-form storytelling, cinematic direction, and prompt creation

Each script lives in its own numbered directory. When a title has not been decided, use `number-untitled` as a temporary name and rename it once the story direction is settled.
